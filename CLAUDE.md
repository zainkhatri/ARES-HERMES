# ARES-DASHBOARD — agent instructions
## Simplified Technical English (asd-ste100 skill)

Apply the `asd-ste100` skill where MISREADING HAS A REAL COST and the text is machine- or
agent-parsed. It makes prompts, errors, and alerts unambiguous; it is not a style preference.

APPLY to: LLM/agent prompts, tool and inter-agent instructions, error messages, log lines,
status reports, and alerts.
DO NOT apply to: user-facing marketing/persuasion copy — STE100 is not for marketing copy.
